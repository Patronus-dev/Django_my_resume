# 👨🏻‍💻 PatronusCode

**PatronusCode**
is a personal website built with Django. It serves as an online resume and portfolio, showcasing projects, contact information, and professional experience.

---
## 🌐 Live Website
[https://patronuscode.com](https://patronuscode.com)

---
## 🚀 Features

- 🌍 Multi-language support (English, German)
- 📄 Resume & personal introduction
- 📈 Animated counters for skills or stats
- 📝 Blog section
- 📬 Contact form with email support
- 📱 Fully responsive design for mobile and desktop
- 🔒 Admin panel for content management
---
## 🛠 Tech Stack

- **Backend**: Django (Python)
- **Frontend**: HTML5, CSS3, JavaScript
- **Database**: PostgreSQL 
- **Deployment**: Docker-based environment (for development)
---
## 📦 Setup & Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/patronuscode.git
cd patronuscode

# Create and activate a virtual environment
python -m venv venv
source venv/bin/activate  # On Windows use venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt

# Apply migrations
python manage.py migrate

# Create a superuser
python manage.py createsuperuser

# Run the development server
python manage.py runserver
```
